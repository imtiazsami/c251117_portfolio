# Project Overview
This is a responsive personal portfolio website developed using *HTML5, CSS3, and JavaScript*. The website showcases my personal profile, education, projects, achievements, publications, blog, and contact information in a clean and modern interface.
The main objective of this project is to provide recruiters, clients, teachers, and visitors with a single platform to learn about my skills, experience, and work.

# Features
- Responsive design for desktop and mobile devices
- Home section with professional introduction
- About Me section
- Education timeline
- Projects showcase
- Achievements section
- Publications section
- Personal blog section
- Contact form
- Social media links
- Download CV button
- Smooth navigation between sections

# Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome Icons

# How to Run the Project Locally
# Step 1: Clone the Repository
git clone https://github.com/imtiazsami/c251111_portfolio.git
# Step 2: Navigate to the Project Folder
# Step 3: Open the Project
Simply open the 'index.html' file in your preferred web browser.
Alternatively, if you use *Visual Studio Code*:  

1. Open the project folder.
2. Install the *Live Server* extension.
3. Right-click on `index.html`.
4. Select *Open with Live Server*
